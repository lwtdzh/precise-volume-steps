# 精准音量 1.5.0 测试版

- 运行模式整理为助手、Shizuku、Root，主页保留一个总开关，按所选模式显示设置入口。
- Root 模式直接使用手机 Root 权限，不依赖 Shizuku 或兼容助手。
- Root 和 Shizuku 支持自动设置标准权限；结果和权限指南提示仍需手动处理的项目，并保留其他无障碍服务。
- 主安装包内置兼容助手，可在主页安装或更新；Android 中仍保留独立助手身份。
- Shizuku 和 Root 的息屏蓝牙调节增加系统粗调屏蔽，松键后写入精调值；修复快速连按时旧松键任务干扰新按键的问题。
- 统一三种后端对明确 stale 写入拒绝的有时限重试，修复系统粗调与精调检查相撞时停留在粗调音量的问题。
- 修复从 Shizuku 切回助手模式后，助手息屏监听可能一直停在“正在连接”的问题。
- 调节范围和诊断移入更多设置。
- 主页根据系统栏和刘海位置留白，避免新版 Android 将标题或底部按钮盖住。

这是开发证书签名的本地测试版。Vivo 的 Shizuku 蓝牙已完成内置实体键、实际 B 站播放和 OPPO Enco X3 听感验证；真实 Root 手机和完整重启矩阵仍需验证。
