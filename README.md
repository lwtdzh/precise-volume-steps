# 精准音量 · Precise Volume Steps

按你设置的档数调节 Android 音量。支持 Android 9 及以上，可选择助手、Shizuku 或 Root 模式。系统实际能调节多少档，取决于手机公开的音量范围。

## 下载与安装

| 运行模式 | 适合谁 | 设置方式 |
|---|---|---|
| 助手模式 | 不想长期运行 Shizuku，手机没有 Root | 开启无障碍；Vivo / iQOO 可从主页安装内置助手，再选择是否做一次性 ADB 授权 |
| Shizuku 模式 | 已在使用 Shizuku，或系统限制后台调节 | 启动 [Shizuku](https://shizuku.rikka.app/)，点击连接并允许授权 |
| Root 模式 | 手机已取得 Root 权限 | 点击授权，在 Root 管理器中允许本应用 |

[下载主应用 1.5.0 测试版](dist/precise-volume-steps-1.5.0.apk)。助手安装包已包含在主应用内，无需另找下载。Android 仍会将助手安装为独立应用，以保留 Vivo 系统所需的应用身份；它没有桌面图标，设置入口在主应用中。这是独立开发的助手，与 vivo 无关联。各机型和固件的息屏行为仍需实测。

## 首次设置

1. 开启 **启用精准音量**，设置 **音量档数**（5–150，默认 30 档）。
2. 在 **运行模式** 中选一个模式。主页只显示该模式所需的设置按钮。
3. 助手模式点击 **开启无障碍服务**；Shizuku 或 Root 模式点击 **连接 Shizuku 并完成设置** 或 **授权 Root 并完成设置**。
4. 在 **权限与后台运行 → 查看权限指南** 检查结果。首次打开也会显示该指南。若无障碍服务尚未连接，请到系统页面开启 **精准音量服务**；若提示“受限设置”，先在应用信息页允许受限设置。

Shizuku 和 Root 可以自动设置通知、悬浮窗、标准后台权限、电池优化豁免和无障碍设置，保留其他已启用的无障碍服务。厂商自启动、关联启动和后台高耗电限制，请按指南到系统页面确认。自动设置失败的项目会在结果中提醒。

**助手模式：** 无需 Root 或 Shizuku，开启无障碍即可使用。Vivo / iQOO 可点击 **安装 / 更新内置助手**，按 Android 提示允许安装，再到 **助手后台权限** 允许关联启动。安装助手可以改善后台写入；可选的 **授权助手息屏按键** 用于监听息屏按键。未授权时仍可亮屏调节，系统若不投递息屏按键，就无法在息屏时修正。

从应用内安装助手需要允许“精准音量”安装未知应用，Vivo 还可能要求指纹或锁屏密码确认。完成安装后可在系统页面关闭安装来源许可，不影响助手运行。

电脑通过 USB ADB 执行一次：

```sh
adb shell pm grant com.vivo.finevolumesteps.helper android.permission.DUMP
```

也可用已经启动的 Shizuku 完成这次授权，之后可停止 Shizuku。该授权在应用和手机重启后保留；卸载助手后需要重新授权。授权保留与服务在重启后是否正常启动是两个独立条件，请检查页面的实际连接状态。

**Shizuku 模式：** 支持通过无线调试或电脑 ADB 启动的 Shizuku v11 及以上。运行期间需要保持 Shizuku 可用，重启后通常需重新启动；无需安装助手或授予助手 DUMP 权限。

**Root 模式：** 本应用直接通过 `su` 启动 Root 服务，音量读写和息屏按键监听均不依赖 Shizuku。授权由手机的 Root 管理器控制，无需安装助手或授予助手 DUMP 权限。模拟器已验证 Root 服务；真实 Root 手机和各厂商固件仍需验证。

**息屏调节：** 检查主页是否显示按键监听已就绪。系统的音量键快捷功能可能同时响应，建议关闭长按音量减快启和息屏双击音量减拍照。息屏长按在松开后按次数或时长调节，通话期间由系统处理。

## 音量面板

面板有三行文字和一条进度条：

```text
媒体音量                  16 / 100%
精准音量 · 当前 8 / 50 阶
系统实际音量 · 24 / 150
━━━━━━━━━━━━━━━━━━━━━━━━
```

顶部是系统音量的百分比，第二行是设置阶数对应的档位，第三行直接读取 Android 的实际音量和上限。修正期间保留上一次实际读数，完成后更新；修正失败时显示实际结果。系统原生音量面板可能仍会短暂显示它自己的默认调节值。

例如系统范围为 0–150、设置 50 阶，从 21 开始按 `+` 会得到 24，再按 `−` 回到 21。不能整除时，相邻增量可能差一个原生单位，来回调节仍沿同一路径。系统只有 15 个调节间隔时，设置更多阶数也无法增加实际精度。

## 遇到问题

- **前台有效、后台无效：** 检查后台权限；vivo 检查助手的关联启动和连接状态，其他手机可尝试 Shizuku。
- **升级或撤销 Shizuku 授权后无效：** 重新打开主应用，检查 **精准音量服务** 是否已连接；必要时在系统设置中关闭再开启该服务。
- **锁屏或熄屏无效：** vivo 助手模式检查页面是否显示“熄屏按键监听已就绪”，否则重新执行一次性 ADB 授权；Shizuku 模式检查 Shizuku 是否运行。两种模式都应检查系统音量键快捷功能。
- **重启后熄屏无效：** 助手的 DUMP 授权正常会跨重启保留；检查助手关联启动、主应用自启动和页面监听状态。Shizuku 模式仍需在重启后重新启动 Shizuku。系统“强行停止”主应用后需重新打开。

复现问题后，在主应用点击 **更多设置与诊断 → 导出运行诊断**。提供机型、系统版本、档数、使用模式，以及问题发生在前台、后台、锁屏还是息屏。**调节范围** 也在更多设置中，默认仅媒体音量。
