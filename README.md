# 精准音量 · Precise Volume Steps

按你设置的阶数调节 Android 音量。支持 Android 9 及以上，无需 Root。系统实际能调节多少档，取决于手机公开的音量范围。

## 下载与安装

| 手机与使用方式 | 需要安装 |
|---|---|
| 普通模式 | [主应用 1.4.14](dist/precise-volume-steps-1.4.14.apk) |
| 已验证的 vivo 固件，想在后台调节且不用 Shizuku | 主应用 + [独立兼容助手 1.1](dist/precise-volume-steps-compatibility-helper-1.1.apk) |
| 普通模式在后台无效，改用 Shizuku | 主应用 + [Shizuku](https://shizuku.rikka.app/)；不需要兼容助手 |
| 系统熄屏时不投递音量键 | 主应用 + ADB 启动的 Shizuku；连接后读取专用音量键设备 |

点击 APK 文件页的下载按钮下载。兼容助手是独立开发的应用，与 vivo 无关联；没有桌面图标，安装后从主应用进入它的设置。iQOO 也会尝试连接助手，但各机型仍需验证。

## 首次设置

1. 打开“精准音量”，开启 **启用音量修正**。
2. 在系统无障碍设置中开启 **精准音量服务**。若提示“受限设置”，先到应用信息页允许受限设置，再返回开启。
3. 按应用提示允许通知、后台运行和音量面板。系统有自启动管理时，也允许主应用自启动。
4. 设置 **音量阶数**（5–150）；默认 30 阶、仅媒体音量。设置即时保存。

**vivo 兼容助手：** 安装两个 APK 后，在主应用中选择 **设置独立兼容助手 → 打开助手权限设置**，允许助手的 **关联启动**。主应用显示“独立兼容助手已连接”后，返回桌面测试音量键。无需每次连接电脑或重启 Shizuku。

**Shizuku：** 按 Shizuku 的说明通过无线调试或电脑 ADB 启动，再在主应用中选择 **设置 Shizuku 连接 → 连接并授权**。本应用支持 ADB 启动的 Shizuku v11 及以上。手机重启后通常需要重新启动 Shizuku；切回 **使用普通模式** 可停止使用它。

**熄屏调节：** 1.4.14 增加了 Shizuku 音量键读取，处理系统未向无障碍服务投递按键的情况。连接后检查主应用是否显示“熄屏按键监听已就绪”；设备不可读取时会提示。它只读取专用音量键和电源键设备，保持屏幕关闭。vivo 需要关闭系统“快捷启动”中的长按音量减，以及相机设置中的“快捷启动相机”（熄屏双击音量减），以免同一按键同时触发快捷功能。熄屏长按在松开后调节。普通模式仍依赖系统投递按键。

## 音量面板

面板有三行文字和一条进度条：

```text
媒体音量                  16 / 100%
精准音量 · 当前 8 / 50 阶
系统实际音量 · 24 / 150
━━━━━━━━━━━━━━━━━━━━━━━━
```

顶部是系统音量的百分比，第二行是设置阶数对应的档位，第三行直接读取 Android 的实际音量和上限。修正期间保留上一次实际读数，完成后更新；修正失败时显示实际结果。系统原生音量面板可能仍会短暂显示它自己的默认调节值。

例如系统范围为 0–150、设置 50 阶，从 21 开始按 `+` 会得到 24，再按 `−` 回到 21。不能整除时，相邻增量可能差一个原生单位，来回调节仍沿同一路径。系统只有 15 个调节间隔时，设置更多阶数也无法增加实际精度。

## 遇到问题

- **前台有效、后台无效：** 检查后台权限；vivo 检查助手的关联启动和连接状态，其他手机可尝试 Shizuku。
- **升级或撤销 Shizuku 授权后无效：** 重新打开主应用，检查 **精准音量服务** 是否已连接；必要时在系统设置中关闭再开启该服务。
- **锁屏或熄屏无效：** 检查 Shizuku 是否已启动并授权，以及系统的音量键快捷功能。vivo V2419A 已测试外接 HID 音量键在熄屏时的调节、唤醒后续按和反向恢复，覆盖未播放媒体和后台播放两种状态；内置物理按键仍需验证。
- **重启后无效：** 检查主应用自启动、后台权限及助手关联启动。已实现开机恢复，但 vivo 真机重启恢复仍需验证。系统“强行停止”后需重新打开应用。

复现问题后，在主应用点击 **导出运行诊断**。提供机型、系统版本、阶数、使用模式，以及问题发生在前台、后台、锁屏还是熄屏。
